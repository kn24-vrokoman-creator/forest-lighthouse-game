# Погодження індивідуального формату виконання Частини 2

Частина 2 у методичних умовах передбачає командну роботу в складі 2–4 осіб. Індивідуальне виконання можливе лише за попереднім погодженням викладача. Цей документ — шаблон звернення, а не підтвердження отриманого дозволу.

## Текст звернення викладачу

Добрий день!

Прошу погодити виконання Частини 2 проєктної роботи індивідуально. У Частині 1 я розробив концепцію навчального проєкту «Таємниця лісового маяка» в ролі Game Designer. Для продовження підготував браузерні прототипи головоломки v0 та v1, критерії приймання, план перевірки, журнал тестування й звіт.

Розумію, що стандартний формат роботи передбачає команду з 2–4 осіб. Прошу повідомити, чи дозволено в моєму випадку продовжити роботу індивідуально та чи потрібно додати окремі матеріали або виконати додаткові умови.

Дякую!
