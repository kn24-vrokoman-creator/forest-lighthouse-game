# Інструкція до повної гри

## Запуск
Відкрий [game/index.html](../game/index.html) у браузері. На сторінці GitHub натисни **Raw**, щоб відкрити або зберегти HTML-файл. Після завантаження файл запускається локально подвійним клацанням; інтернет для гри не потрібен.

## Мета
Знайти три печатки лісу, води та зорі, а потім відкрити старий маяк і завершити пригоду.

## Керування
- **W / ↑** — рух угору.
- **S / ↓** — рух униз.
- **A / ←** — рух ліворуч.
- **D / →** — рух праворуч.
- **E** або **Enter** — взаємодія з місцем поруч.
- **Escape** — закрити вікно загадки.
- Екранні стрілки — керування на сенсорних пристроях.
- Кнопка **Почати спочатку** — скинути проходження.

## Проходження
1. На Галявині шепоту (🍃) розв'яжи загадку про фотосинтез.
2. Біля Тихого озера (💧) дай відповідь про перетворення води на лід.
3. Біля Старих руїн (⭐) розв'яжи загадку про п'ятикутну зірку.
4. Після отримання всіх трьох печаток підійди до Старого маяка (🏰) та натисни E.
5. З'явиться фінальне вікно про завершення пригоди. Можна почати нове проходження.

## Примітки
- Якщо відповідь неправильна, гра показує підказку та дозволяє спробувати знову.
- Дерева й камені блокують рух.
- Це завершена коротка навчальна браузерна гра з трьома загадками; вона не є великою комерційною грою або 3D-проєктом.
- Файл не використовує зовнішні бібліотеки, сервер або сторонні графічні ресурси.
