# Перевірка повної гри

## Перевірки, виконані під час підготовки
- [x] HTML-файл збережений у репозиторії.
- [x] JavaScript усередині HTML успішно проходить синтаксичний розбір.
- [x] У файлі присутні стартове меню, три локації із загадками, фінальний маяк, клавіатурне та екранне керування, перезапуск і фінальне вікно.

Ці перевірки підтверджують наявність основних компонентів і синтаксичну коректність скрипту, але не є повним запуском у браузері.

## Ручні перевірки перед здачею
| ID | Дія | Очікуваний результат | Статус |
|---|---|---|---|
| G-01 | Завантажити HTML і відкрити у браузері | Відображається стартове меню | Не перевірено вручну |
| G-02 | Натиснути «Почати пригоду» | Відкривається мапа, персонаж на старті | Не перевірено вручну |
| G-03 | Переміщатися WASD і стрілками | Персонаж рухається, дерева й камені блокують шлях | Не перевірено вручну |
| G-04 | Взаємодіяти з кожною з трьох локацій | Відкривається відповідна загадка | Не перевірено вручну |
| G-05 | Дати неправильну відповідь | З'являється підказка, можна повторити спробу | Не перевірено вручну |
| G-06 | Правильно відповісти на всі три загадки | У щоденнику відображаються всі печатки | Не перевірено вручну |
| G-07 | Взаємодіяти з маяком до збору печаток | Маяк повідомляє, що потрібні всі печатки | Не перевірено вручну |
| G-08 | Після збору печаток взаємодіяти з маяком | З'являється фінальне вікно завершення | Не перевірено вручну |
| G-09 | Натиснути «Зіграти ще раз» | Стан гри скидається, можна пройти заново | Не перевірено вручну |
| G-10 | Перевірити екранні стрілки на телефоні | Персонаж рухається кнопками на екрані | Не перевірено вручну |

## Відомі межі
Ручне тестування в реальному браузері та на телефоні ще потрібно провести. У звіті не слід позначати ці перевірки як виконані, доки їх не пройдено фактично.
