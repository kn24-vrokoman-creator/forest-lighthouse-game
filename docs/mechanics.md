# Механіки та ігровий цикл

## Основна механіка
Гравець досліджує доступну частину лісу, знаходить предмет і використовує його на відповідному об'єкті. Щоб пройти далі, потрібно розв'язати головоломку з трьома світловими символами: активувати їх у правильному порядку, який підказують малюнки на каменях.

## Керування (план)
- WASD / стрілки — переміщення.
- E — взаємодія з предметом або механізмом.
- Esc — пауза.
Для паперового прототипу ці дії можна замінити картками та жетонами.

## Core loop
1. **Дослідження:** оглянути доступну зону.
2. **Спостереження:** знайти візуальну підказку.
3. **Пошук:** підібрати предмет або визначити послідовність.
4. **Взаємодія:** застосувати предмет / активувати символи.
5. **Зворотний зв'язок:** отримати світловий сигнал про правильну дію.
6. **Прогрес:** відкрити нову ділянку й наблизитися до маяка.

## Правила головоломки
- Є три символи: листок, крапля та зірка.
- На стежці гравець знаходить підказку з порядком символів.
- Натискання не того символу скидає поточну послідовність і дає короткий сигнал.
- Правильна послідовність активує механізм і відкриває прохід.
- Після успіху стан механізму зберігається.

## Зворотний зв'язок
Правильна дія: символ світиться, звучить короткий дзвін, індикатор прогресу оновлюється. Помилка: символ м'яко блимає, послідовність починається знову. Важливо, щоб результат був зрозумілий без текстового пояснення.

## Метрики для перевірки
- Час до першої правильної взаємодії.
- Частка тестувальників, які розуміють мету без підказки.
- Кількість помилкових натискань.
- Час проходження головоломки.
- Суб'єктивна оцінка зрозумілості за шкалою 1–5.
