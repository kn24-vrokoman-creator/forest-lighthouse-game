# План наступної частини проєкту

## Мета
Перетворити перевірену концепцію на мінімальний ігровий прототип однієї локації.

## Заплановані етапи
| Етап | Робота | Результат |
|---|---|---|
| 1 | Уточнити правила після тестів | Оновлений опис механіки |
| 2 | Створити схему локації та UI | Макет одного рівня |
| 3 | Реалізувати переміщення й взаємодію | Керований персонаж |
| 4 | Реалізувати головоломку | Робоча послідовність символів |
| 5 | Додати відкриття проходу та фінал | Мінімальний ігровий цикл |
| 6 | Провести тестування | Список проблем і покращень |

## Мінімальні критерії готовності
- Гравець може переміщатися локацією.
- Предмет можна знайти та підібрати.
- Головоломка реагує на правильні й неправильні дії.
- Після правильної послідовності відкривається прохід.
- Є зрозумілий сигнал завершення рівня.

## Ризики
- Підказка може бути непомітною — перевірити контраст і розташування.
- Головоломка може бути надто легкою або складною — протестувати кілька варіантів порядку.
- Гравець може не зрозуміти взаємодію — додати короткий візуальний індикатор біля активних об'єктів.

## Результат наступної частини
Вертикальний зріз: одна невелика локація, одна головоломка та завершений цикл від дослідження до відкриття проходу.
