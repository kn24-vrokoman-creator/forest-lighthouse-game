## Паспорт проєкту
| Параметр | Значення |
|---|---|
| Назва | Таємниця лісового маяка |
| Жанр | 2D пригодницька головоломка |

## Статус
Це концептуальний навчальний проєкт. Прототипи на цьому етапі є паперовими/схематичними моделями механіки, а не завершеною грою.

## Авторство та внесок
Індивідуальний навчальний проєкт. Автор: **вкажіть ПІБ перед здачею**. Роль: Game Designer — концепція, механіки, аналіз аналогів, алгоритм, прототипування та планування.
